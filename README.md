# SoundSplit Qt source materials

This repository publishes Qt/PySide 6.11.2 source materials associated with the Qt components found in SoundSplit 1.0.3 and the source/build settings for a tested, modified Qt Core replacement library.

## Download

[Download the source bundle](https://github.com/CodigoTriptonico/SoundSplit-Sources/releases/latest/download/SoundSplit-Qt-6.11.2-sources.zip)

The bundle includes upstream Qt/PySide source archives, the Qt Core replacement patch and build configuration, Qt's build-time SPDX output, and the LGPL v3 text. The SPDX output is marked by Qt as build-time/testing material and has no checksums; it is not a complete production SBOM.

The original Windows wheel did not include its platform-specific build configuration, patch set, or SBOM. This publication does not claim exact binary provenance for every original Qt/PySide wheel file. The included source and configuration reproduce the Qt Core replacement that was loaded by SoundSplit from a clean portable extraction.

The proprietary SoundSplit application source is not included. For source-bundle questions or feedback, use [SoundSplit Feedback](https://github.com/CodigoTriptonico/SoundSplit-Feedback/issues).
